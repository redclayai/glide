## Fixed

**Rewrites no longer leave two sentences drawn on top of each other in web editors.**

Accepting a grammar suggestion inside a Chromium-rendered editor — Millie, and anything else built on
a web view or Electron — could leave the old text and the new text painted over one another. The
document underneath was correct; the editor simply never repainted the line, because Glide posted the
whole replacement in one burst rather than the way text arrives when a person types it.

Replacements are now paced, and web-rendered fields receive the text in smaller pieces. A
sentence-length rewrite takes about a fifth of a second to write instead of landing all at once.

This is a fix reasoned from the mechanism rather than one reproduced on demand — the artifact was
intermittent. If you see it again, say so: the next step is a per-app override.

See ADR-131 in `docs/05-decisions.md`.
