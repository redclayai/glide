## Improved rewrite experience

- A small badge appears beside selected text. Click it to open the rewrite card when you need it.
- The card groups actions into tabs, keeps the custom instruction field visible, and shows proposed edits with highlighted additions and removals.
- Progress messages show when spelling and grammar checks are running. A timeout clears a stuck check instead of leaving its spinner running indefinitely.
- Optional automatic checking is available in Settings → General. Spelling uses the Mac’s dictionary; grammar uses your configured local or cloud backend.

## Reliability fixes

- Keyboard-shortcut rewrites are discarded if you type, click, switch applications, or change the destination while a rewrite is running. Glide checks the original destination again before posting the paste.
- Selection rewrite clipboard handling preserves images, rich formatting, and multiple items. Delayed restoration leaves newer clipboard contents alone.
- Local grammar corrections use sentence-aware look-ahead so abbreviations, decimal numbers, and unfinished final sentences are handled more carefully.
- Corrections stop before unwanted repeated output. Grammar suggestions are checked to reject results that stray too far from your original text.
- The card no longer reopens immediately on text you just corrected, retains stale results from a previous selection, or jumps around as its content changes.
- Selection replacement and application compatibility have been improved, including support for Millie’s web-rendered fields.
- Spelling checks handle several nearby typos more reliably and avoid some inappropriate corrections of names and product terms.

## Privacy and verification

Local processing remains the default. Optional Claude and Gemini rewrite backends send the selected text to the provider you configure with your own API key. The documentation now makes this distinction explicit.

This release includes regression tests for sentence boundaries, destination changes, and clipboard preservation. The proofreading suite and the three app safety tests passed before release preparation.
