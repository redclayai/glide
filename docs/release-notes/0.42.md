## Changed

**Grammar now actually fixes spelling.**

Its prompt always said "correct the spelling" — but that's a request, and the on-device model is a
base model that doesn't honour requests. Asking it to fix typos achieved close to nothing.

Spelling is no longer the model's job. Grammar now runs macOS's own spell checker over your selection
first, deterministically and offline, and only then asks the model for the part it's genuinely good
at: grammar and punctuation.

- "This is a **testt**." → "This is a test."
- "I'm **definately** going to **seperate** these." → "definitely … separate"
- "The **recieved** invoice was **inccorect**." → "received … incorrect"

**Your names are safe.** A capitalised word mid-sentence is a product or a person far more often than
a typo, so those are left alone — the checker's first suggestion for "Cueo" is "Cleo", which is a
rename, not a correction. Words that open a sentence are still fixed, so "Teh meeting" becomes "The
meeting" and keeps its capital.

**And Grammar works with no model at all.** If the language model is missing or fails, the spelling
pass still lands — half a fix beats an error message. Given the model file went missing last week,
that matters.
