## Fixed

**Glide now tells you when it has no language model.**

If the model file is missing, autocomplete cannot run. Until now it simply didn't — no message, no
change in the menu bar, nothing in the log that anyone reads. The only record was an `os_log` line.
The failure was indistinguishable from the feature being broken, which is exactly what it looked like.

The menu bar now says **"No language model installed"** with **Install a Model…** next to it, and the
reason is written to the prediction log:

```
ENGINE unavailable model=Qwen3.5-2B-Base.i1-Q4_K_M.gguf — Model file not found in …/KeyType/Models
```

This is worth knowing because the model lives in Application Support and is 1.2 GB — large enough
that disk-cleanup tools and macOS storage optimisation can remove it without asking. Glide never
deletes it; clearing personal data only touches history and telemetry.
