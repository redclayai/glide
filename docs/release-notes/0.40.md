## Fixed

**Closing the toolbar now closes it.**

The × button, Escape and the automatic 15-second dismissal all worked — and were all undone within a
third of a second. Dismissing forgot which selection it had been showing for, so the next check saw
the very same selection as brand new and put the panel straight back. It reappeared before your
finger left the mouse, which is why it looked like the close button did nothing.

**And it no longer appears on its own.** Same cause: text left selected in a window kept
re-triggering the panel forever, every time the 15-second cap dismissed it. Nothing needed to be
typed — an idle selection was enough.

A dismissal is now remembered against the selection it was for. Deselect and select the same words
again and the toolbar comes back, because dismissing means "not for this selection", not "never for
this text".
