## Added

**The selection toolbar has 35 actions instead of two, and picks the right ones for what you selected.**

Select a link and it offers to open it. Select one word and it offers to define it. Select a
paragraph and it offers to summarize it. Select several lines and it offers to sort, join or
de-duplicate them. Select code and it offers to explain or comment it. Anything that doesn't fit in
the capsule goes into a `···` overflow menu.

Most of the new actions are offline: case conversion, trimming, slug, Base64, URL encoding, line
operations, JSON formatting, character and word count. They're instant, free, and work with the
network off. The AI ones — Summarize, Make shorter, Expand, To bullets, More formal, More casual,
To English, Explain, Draft reply — go through whichever engine you've already configured.

Not every action replaces your text. Explain and Count show their answer in the capsule and leave the
document alone. Draft reply copies to the clipboard. Open link, Search, Define, Email and Map open a
URL.

**How the ordering works**, in descending authority: anything you pin, then how well the action fits
what you selected, then what you've used recently (fading over about three days), then a fixed
default order as the tie-break. Those are on separate scales rather than blended, so the order is a
guarantee rather than an aspiration — a pinned action is always first, and a perfect match for the
selection can't be buried by a habit.

## Notes

Settings for pinning, reordering and disabling actions — and for writing your own in JavaScript,
shell, AppleScript or as a URL template — are built underneath but not yet exposed. The engine
supports six kinds of action; this release ships the built-in catalogue only. Shell and AppleScript
execution is off and has no switch yet, by design: it arrives with the settings pane that explains it.

See ADR-137.
