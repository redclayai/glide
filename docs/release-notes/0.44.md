## Fixed

**Prompts are now built for whichever model you've selected.**

Glide hardcoded one model's chat format (Qwen's ChatML) into every prompt. Select a model that uses a
different format — or none — and those markers arrived as literal text, which is why AI actions
returned pages of `<think>` instead of a rewrite.

Prompts are now formatted with the model's own chat template, handed to llama.cpp, which knows the
published formats. A model that ships no template gets plain text instead of someone else's markers.

Measured on the same sentence:

- Gemma 4 E4B — before: `</think></think></think>…`  ·  after: clean output
- Qwen3.5-2B-Base — unchanged, correct in both

**Model details are now read from the file**, so the architecture (`qwen35`, `gemma4`) and chat
template come from the GGUF rather than being assumed.

## Note on models

Glide's actions are tuned for **Qwen3.5-2B-Base**, which is the default. If you have Gemma 4 E4B
installed: it ships no chat template and does not follow instructions, so Summarize, Expand and the
tone actions will return your text unchanged. It is not an upgrade. Qwen is the one to stay on.
