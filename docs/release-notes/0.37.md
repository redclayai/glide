## Fixed

**The toolbar no longer jumps around while you use it.**

0.35 fixed one cause and missed two others. All three are now covered.

**The selection text itself flickers.** Not just trailing whitespace — apps report genuinely
different text between reads. Measured in your own logs: the same selection alternating between 6 and
36 characters several times a second as the read resolves against different elements. Every flip
looked like a real selection change, so the panel rebuilt and re-anchored on each one. A changed
selection now has to hold for two consecutive checks before a visible panel acts on it.

**The anchor wanders.** What macOS hands back for a selection is often a 1pt-wide *caret* rectangle,
and it drifts by tens of points while you do nothing but move the mouse. Following it faithfully is
what "the menu keeps moving" is. A visible panel now stays where it is and only updates its contents,
unless the selection genuinely moved somewhere else — more than about 220pt away.

**And the panel changed width as it rebuilt,** which moved it even when the anchor held still, because
it's centred on the selection. Rebuilding in place fixes that too.

The two-consecutive-checks rule applies only while the panel is already visible. Applied to the first
appearance as well, an app that alternates forever would never satisfy it and the toolbar would never
show up at all — trading a panel that jitters for one that doesn't exist.
