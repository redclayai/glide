## Added

**Custom actions, and a Settings pane to arrange them.**

Settings → **Actions** now lists everything the selection toolbar can do. For each one you can turn
it off, pin it so it always appears first, or drag it into the order you want. Built-in actions can
be arranged but not rewritten; your own can be edited and deleted.

**New Action** creates one of five kinds:

- **Text Transformation** — pick from the built-in transforms (case, trim, slug, Base64, line
  operations…).
- **AI Prompt** — a reusable instruction run against your selection with whichever engine you have
  configured.
- **JavaScript** — the selection arrives as `text`; write an expression or a body with `return`. It
  runs with no network and no filesystem access.
- **Terminal Command** — the selection arrives on stdin, and `{{text}}` is substituted as a safely
  quoted argument.
- **AppleScript** — `{{text}}` is substituted as an escaped string literal.
- **Link** — `{{text}}` is URL-encoded into a template; `{{text|raw}}` goes in verbatim.

Each action chooses what happens to its result: replace the selection, copy it, open it as a URL, or
just show it. There's a **Try it** field so you can run an action against sample text while you write
it — and it runs through exactly the same engine the toolbar uses, not a simulation of it.

## Security

**Shell and AppleScript actions are off until you turn them on**, behind a switch in the same pane
that explains what they do. They run with your own permissions. They're offered because you write
them yourself — Glide has no way to import one from anywhere — and gated because "you wrote it" is a
weaker guarantee the moment a command can be pasted in from somewhere else.

Text substituted into a shell command is **single-quoted and escaped**. Your selection is not
something you wrote — it comes from whatever app you were reading — so a selection containing
`'; rm -rf ~ #` would otherwise end your quoting and run as a command. There are tests for that case
and for `$HOME`, backticks, `$(…)`, pipes and globs.

See ADR-139.
