## Added

**⌃⌥A opens your actions in any app.**

The toolbar appears on its own only where an app tells macOS what you have selected. Plenty don't —
Millie reports no selection on every check — so in those apps the toolbar never appeared and your own
actions were unreachable exactly where you might most want them.

⌃⌥A asks the app for its selection directly instead, which works everywhere. The action list opens
at the pointer, ranked for whatever you selected, and the result is pasted back. Custom actions are
now genuinely available in every app rather than in most of them.

## Fixed

**The "Allow commands and scripts" switch is now actually on screen.** It shipped in 0.32 as code
that was never placed in any view, which left shell and AppleScript actions permanently unreachable —
a switch that exists in the source and not in the window is the same as no switch. It sits at the
bottom of the Actions pane, alongside a note about ⌃⌥A.

**JavaScript actions accept the conventions other tools use.** A snippet written as
`function run(selected_text) { return selected_text.trim(); }` defined the function and never called
it, so it evaluated to nothing and reported "the action produced no text". Three shapes now work:

- a bare expression — `JSON.stringify(JSON.parse(text), null, 2)`
- a body with `return` — `var n = text.length; return n + " chars";`
- a named entry point — `function run(selected_text) { … }`

`selected_text` is bound alongside `text`, so a snippet copied from elsewhere runs unchanged. New
JavaScript actions start from the `run` form.

See ADR-140.
