## Fixed

**Accepting a grammar fix in Electron apps no longer inserts the correction in front of the original.**

In Claude Desktop, Millie, Slack and other web-rendered editors, pressing Tab produced
`"OK, I think this is working.Ok I think this is working"` — the new sentence added, the old one
left behind.

The cause was two layers deep. Glide tries the accessibility API first, because it is the only
replacement method whose result can be verified. Chromium answers that write with "success" and then
silently discards it. Glide's verification correctly caught the lie and fell back to synthesizing
keystrokes — but it returned without collapsing the caret first, so the text was still *selected*
when the fallback began. The shift-arrow run then extended that existing selection instead of making
a new one, ending up with a partial, wrong span, and the replacement was typed at the front.

Two changes: Glide no longer attempts the accessibility write in web-rendered fields at all, since it
cannot succeed there; and a write that reports success but fails verification now restores the caret
before returning, so the keystroke fallback always starts from a known state.

Measured in Claude Desktop: with the accessibility attempt, the replacement landed in front of the
original on every attempt. Without it, the keystroke path was correct on every attempt.

See ADR-133.

**And the safety check no longer rejects a replacement that was about to work.**

Glide verifies the text is really selected before typing over it. It was taking that reading too
early: a Chromium field applies a synthesized arrow run asynchronously, so a 26-character selection
reads back as empty at 0 ms, one character at 25 ms, and only becomes whole at about 75 ms. Glide
checked at 35 ms, saw a partial selection, and correctly refused to type — which meant the
correction silently did nothing.

It now waits for the selection it asked for rather than sampling once, returning as soon as the app
agrees and giving up after half a second. A genuinely failed selection is still abandoned rather
than typed over.
