## Fixed

**The toolbar appears on secondary displays.** It was being placed thousands of points off-screen for
any app on a display mounted above your primary one. Glide converts the selection's coordinates from
the screen coordinate space to AppKit's, and the flip has to be about the *primary* display's top
edge — it was flipping about whichever display the selection was on, which is the same number only
when that display is the primary. The panel wasn't missing; it was somewhere nobody could see.

## Changed

**The toolbar follows the requested spec:** `.popover` vibrancy material, a 1px high-contrast border,
a 10pt continuous corner radius, 13pt system type, no vertical dividers — padding does the
separating — and system `chevron.down` glyphs on the group buttons instead of a literal "⌄".

## Repository

**Two source files had never been committed.** `.gitignore` contained `Models/`, meant for GGUF model
weights, but the pattern was unanchored so it also matched `KeyType/Logic/Models/` — a source
directory. `SelectionRewrite.swift`, which is the entire selection toolbar, and
`ModelSetupCoordinator.swift` were both excluded from version control. The repository has not built
from a clean clone for months; nobody noticed because everyone building it already had the files.
The rule is now anchored to the one directory that ever held weights, and both files are in.

See ADR-143.
