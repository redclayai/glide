## Added

**See what an AI action produced before it touches your text.**

Rewrites used to apply the moment the model answered. You couldn't see what a rewrite had done to
your sentence until it had already replaced it, and the only way back was undo — in whatever app you
happened to be in.

Now an AI action shows **Working on it… / Cancel** while it runs, then the result with **Replace**
and **Copy**. Return accepts it; Escape or the × discards it and your text is untouched.

Offline transforms are unchanged and still apply instantly. Confirming "UPPERCASE" would be friction
with nothing on the other side of it.

**Actions are grouped.**

With 35 actions eligible for a given selection, one unlabelled `···` button was a list nobody reads.
The best-matching actions for what you selected still stand alone — select a link and "Open link" is
still the first button — and everything else collapses into named menus: **Writing**, **AI**,
**Text**, **Lines**, **Encode**, **Code**.

Grouping is named overflow, not a replacement for ranking. A pinned action is never grouped, because
a pin means "put this where I can click it". Nothing eligible is ever dropped — there's a test for
that.

See ADR-141.
